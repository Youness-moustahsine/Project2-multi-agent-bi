# Multi-Agent Business Intelligence (prototype)

A supervisor agent receives a business question in natural language, decides which specialised agents
to call, and returns a decision-ready answer with charts, SQL traceability and a forecast.

## Architecture

```
Question -> Supervisor (plan, routing, error recovery)
             |-> SQL Agent       (tool calling: describe_schema, run_sql  -> datasets)
             |-> Data Analyst    (tool calling: list_datasets, stats      -> insights)
             |-> Forecast Agent  (tool calling: forecast + backtest MAPE  -> projection)
             '-> Business Advisor (synthesis -> answer + prioritized recommendations)
```

- Shared state: datasets, forecasts and findings are passed between agents (`app/state.py`)
- Safety: read-only SQLite connection + SQL validation (single SELECT only) + row limit
- Error recovery: SQL errors are fed back to the agent; the supervisor retries a failed SQL step
- Forecasting: pure-Python linear trend + multiplicative seasonality, 80% interval, backtest MAPE
- Demo data: 34 months of B2B sales (customers, products, orders, order_items) generated by `seed.py`
- LLM: Groq (Llama) with automatic model discovery and failover (`app/llm.py`)

## Run

```
python -m venv .venv
.venv\Scripts\Activate.ps1          # Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env              # put your GROQ_API_KEY in .env
python list_models.py               # optional: models available for your key
uvicorn app.api:app --reload        # http://127.0.0.1:8000 (demo DB auto-created)
```

CLI: `python cli.py "Quelle catégorie croît le plus vite ?"` — Tests: `pytest -q`

## Plug your own data
Set `DB_PATH` to any SQLite file; the agents discover the schema themselves
(adapt `DOMAIN_HINTS` in `app/db.py` for your business metrics).
